# space_ship

Pyxel 製のロケット操縦ゲーム。
[pyxel_sandbox](https://github.com/airpocket-soundman/pyxel_sandbox) の `rocket/rocket_thrast_control.py` をベースに開発。

## ブラウザで遊ぶ (Pyxel Web Launcher)

https://kitao.github.io/pyxel/wasm/launcher/?run=airpocket-soundman.space_ship.space_ship

## ローカルで実行

```
pip install pyxel
python space_ship.py
```

## 操作

| キー | 動作 |
|---|---|
| Space | 噴射 |
| ↑ / ↓ | 推力調整 |
| ← / → | 回転 |
| R | リセット |
